# v1.4.0-sauna.3 — Admin form routes

A control named `action` shadowed the form's `action` property. Saving or clearing the Hi-Fi bridge and valve settings could therefore POST to `/[object HTMLInputElement]` and report HTTP 404. The Dial admin now reads the declared form action attribute, preserving same-origin validation and the submitted button value. Browser tests cover both save and clear routes, session expiry, and rejection of a foreign action.

This release also corrects the independent light connection example for this installation: `http://<Pi-LAN-IP>:8082`. Shower and weather use port 8081. The light requires separate display and settings credentials.

The owner's Waveshare Dial already ran a locally built image with the form fix and retained NVS after an app-only flash on 2026-10-18. That local verification is separate from the exact CI artifact for this new tag. The published v1.4.0-sauna.2 image remains the rollback artifact; this release does not replace it in place. Pi v1.4.0 operating notes describe the manual time-ready recovery after a late clock synchronization. No physical valve or lamp acceptance is implied by this firmware release.
