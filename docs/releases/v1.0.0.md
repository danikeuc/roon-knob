# Outdoor shower controller v1.0.0

This release pairs the Raspberry Pi service with the custom Waveshare ESP32-S3
Roon/shower firmware. Its supported operating scope is `manual_timed`: an
intentional shower action allows supply for ten minutes, with paired DRAIN
control. PT100/MAX31865 temperature is informational and displayed only on
the shower page, with one decimal and a comma.

## Acceptance

Verified by operator observation on the recorded candidate: shower temperature
placement, Hub loss/recovery, Wi-Fi loss/recovery, Roon play/pause and volume,
and return to shower temperature/OFF. One sequential reference comparison was
24.3 °C on the dial and 24.4 °C on the independent thermometer.

Physical sensor-fault testing was explicitly skipped by the operator for this
informational scope. Lower-temperature comparison is deferred as currently
unavailable. Neither is a passed test. Repeated reference pairs, calibrated
accuracy, hardware stale-telemetry behavior with a reachable API and extreme
glyph legibility remain evidence limits.

This release does not commission automatic temperature/weather control.
Physical actuator communication-loss, crash/hang, reset and power-loss outcomes
remain unverified for this candidate. A UI OFF indication or GPIO level does
not prove valve position. Release publication does not authorize new actuation.

## Install and rollback

Pi: use the existing reviewed deployment procedure and virtual environment.
Preserve configuration and credentials; retain `manual_timed`. This release
does not require an immediate reinstall of the already observed source.

Dial: use the attached four-region files with their flash instructions and
SHA-256 manifest. Preserve NVS; no whole-chip erase is required. Keep 24 V valve
power disconnected during any separately authorized deployment or flash.
